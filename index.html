Course overview

This course introduces the data science pipeline: understanding data, preparing it, mining patterns, building and evaluating simple models, and communicating results responsibly. Learning is hands-on, case-based and supported by AI tools used with disclosure.

Course outcomes
  • CO1 Explain the data science lifecycle, types of data and applications (K2).
  • CO2 Apply data collection, cleaning and pre-processing techniques using Python (K3).
  • CO3 Apply basic data mining techniques: association rules, classification, clustering (K3).
  • CO4 Analyse basic machine learning models using evaluation metrics (K4).
  • CO5 Evaluate visualisations and data-driven decisions for effectiveness, fairness and ethics (K5).
